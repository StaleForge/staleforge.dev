## 🇬🇧 English

Welcome! This repository serves as a showcase and description of my personal portfolio website available at **[staleforge.dev](https://staleforge.dev)**. 

> **Note:** This repository does not contain the source code. It acts as a placeholder to present the project on my GitHub profile.

### About the site
The website was built with a focus on speed, performance, and modern web standards. 

**Tech Stack:**
* **[Astro.js](https://astro.build/)** - The core framework, chosen for its lightning-fast static site generation and zero-JS default approach.
* **[React](https://react.dev/)** - Used for interactive UI components where dynamic functionality was needed.

👉 **Visit the live site:** [staleforge.dev](https://staleforge.dev)
